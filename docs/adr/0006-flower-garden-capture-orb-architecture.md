# Capture orb: three-ring concentric petal structure for the flower-garden theme

The flower-garden theme needed a capture enclosure for the table exercise, the role filled by the capture bubble in the undersea theme. We chose a three-ring concentric petal structure (invisible rings at fractional radii, each with independent rotation, petals distributed around the circumference) over a bubble PNG with a texture shader (the undersea approach), a single-particle cloud, or a static flower image. The petal-ring model shares visual language with the butterfly-wing UV-stretch shader already in the theme, reuses the 21 orphan petal PNGs on disk, and gives distinct idle motion (ring rotation + petal self-spin + Brownian radial drift) that the bubble's wobble-only idle lacks. Enter uses spiral-in cluster flight from the roamer tap point instead of straight-line lerp; burst uses outward scatter instead of scale-up+fade. The three-tier z-order (roamer behind all rings, inner on top of outer) ensures the creature stays visible through petal gaps.
